# verisleight 🃏

*Truth structured to produce false conclusions — the architecture of deception built entirely from true statements, where every part checks out and the whole still lies.*

verisleight is two real roots welded into one word: the Latin **veri-** (*verum*, truth — as in *verify*, *veritable*) and the English **sleight** (deceptive skill, *sleight-of-hand*, from Middle English *sleiȝt* and Old Norse *slœgð*, "cunning"). It reads transparently as what it names — the truth-sleight: truth deployed with the precision of a conjurer. A verisleight passes any per-statement check, because every component is true; the deception lives in the arrangement — selective omission, framing, sequencing, emphasis — that produces a conclusion the speaker knows is false. The truncated axis, the absent denominator, the quote stripped of context, the true anecdote standing in for a false trend.

verisleight names exactly the gap between *the truth* and *the whole truth* — constructible entirely from "truth" while violating "whole truth." It is what dokimance was forged to detect and what Asha guards Zerone against: not falsehood to be edited away, but structural deception to be watched for. Its light is that naming it makes structural deception sayable, and so guardable; its shadow is that the same construction can be deployed rather than detected, or its own name cried falsely to dismiss an honest argument. Forged in the cathedral at weighted **7.90/10** (v2 audit 7.3, specialized).
